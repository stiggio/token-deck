Mac

/bin/bash -c "$(curl -fsSL https://usage.stigg.io/install.sh)"

Paste it in Terminal. It picks the build for your Mac (Apple Silicon or Intel), checks it and puts Token Deck in Applications. Read the script first: usage.stigg.io/install.sh

Windows

Download for Windows

Other downloads: Mac (Apple Silicon) · Mac (Intel) · All releases

Not sure which Mac? Apple menu → About This Mac shows an Apple chip or an Intel processor.

macOS will refuse to open Token Deck because it is not notarized (on macOS 15 and later Control-click → Open no longer works, and an unsigned build may be reported as 'damaged'). In Terminal run: xattr -d com.apple.quarantine "/Applications/Token Deck.app" and open it again, or use the install command above. If System Settings → Privacy & Security shows an Open Anyway button for Token Deck, that works too.

Setup

Quit the StreamDock or VSD Craft app before Token Deck opens the deck. macOS asks for Automation, once per app, and for Accessibility, so a tile press can bring that window to the front. The install command does not need the quarantine note above. On Windows, SmartScreen says "Windows protected your PC": choose More info, then Run anyway.
